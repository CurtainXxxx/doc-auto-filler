# 知识文件难度梯度设计规则

## 核心原则

**同一模板的简单/中等/困难三个文件，底层数据必须完全一致，只有表达方式不同。**

这样测试的变量只有一个：输入质量。如果不同难度用了不同数据，就无法判断是输入难导致的低填充率，还是信息本身缺失导致的。

---

## 三级难度定义

### 【简单】— 结构化表单式文本
- 格式：分段落、有标签、键值对形式
- 语言：直接陈述，无冗余
- 示例：
  ```
  教师姓名：张明
  课程名称：数据结构
  学时数：64
  学生人数：52
  ```

### 【中等】— 自然语言叙述
- 格式：连贯的段落文字，无明确标签
- 语言：正常的书面表达，信息嵌入在叙述中
- 示例：
  ```
  张明教授这学期教数据结构，64学时的必修课，班上52个学生。
  ```

### 【困难】— 口语化碎片转述
- 格式：口语对话、间接转述、信息碎片化
- 语言：随意的口语，代词替代、省略、表达不规范
- 示例：
  ```
  张老师说数据结构那门课班上52个人，必修课64课时。
  ```

---

## 关键规则

### 规则1：信息量等同
三个文件包含的**信息条目完全相同**。不能简单版缺字段、困难版补字段。
- ❌ 简单版没有日期，困难版有日期 → 不公平
- ✅ 三个版本都有日期，只是表达方式不同

### 规则2：年份必须明确
所有日期必须带年份。
- ❌ `3月10号` → Agent 不知道哪一年
- ✅ `2024年3月10号`
- 跨年的要注意：2024-2025第一学期的考试在2025年1月，不是2024年1月

### 规则3：数据一致性
同一个模板的三个难度文件，所有字段值必须相同。
- 教师都是张明，不能简单版张明、困难版李华
- 分数都是76.8，不能中等版76.8、困难版78.5

### 规则4：难度只体现在"提取难度"上
| 维度 | 简单 | 中等 | 困难 |
|------|------|------|------|
| 信息结构化程度 | 高（键值对） | 中（段落） | 低（碎片） |
| 语言规范程度 | 规范书面语 | 自然书面语 | 口语/省略/代词 |
| 是否需要语义理解 | 几乎不需要 | 需要 | 高度需要 |
| 正则匹配能否兜底 | 能覆盖大部分 | 能覆盖部分 | 只能覆盖少数 |

## 已验证的6个模板 × 3级难度对照

以"考场记录表"为例，三个版本同一份数据：

**数据池**：考试课程=数据结构、日期=2024年1月15日 9:00-11:00、教室=二教2203、院系=计算机与智能教育学院、应到45实到43、缺考=陈小明(2022080101)+赵丽丽(2022080123)、闭卷、主讲=张明、班主任=刘伟、监考=黄强+王丽

**简单版**（结构化）：
```
考试课程：数据结构
考试时间：2024年1月15日 上午 9:00-11:00
...
```
→ Agent 直接按标签匹配，几乎不需要理解

**中等版**（叙述）：
```
2024年1月15号上午9点到11点，二教2203教室考的数据结构，计算机与智能教育学院的。应到45人实到43人，有两个缺考的——陈小明2022080101，赵丽丽2022080123...
```
→ Agent 需要从一段话里识别：哪个是时间、哪个是课程名、哪个是人数

**困难版**（口语）：
```
张老师，2024年1月15号上午数据结构考完了，在二教2203。45个人来了43个，陈小明和赵丽丽没来，学号分别是2022080101和2022080123。试卷没啥问题，闭卷考的...
```
→ Agent 需要理解："考完了"暗示这是考试课程、"45个人来了43个"暗示应到和实到、"没来"暗示缺考

---

## 科学意义

这样设计可以**量化分析系统对不同输入质量的鲁棒性**：
- 简单→中等 的填充率下降 = 系统在"失去结构化标签"后的性能损失
- 中等→困难 的填充率下降 = 系统在"面临口语化表达"后的性能损失
- 简单→困难 的总降幅 = 系统对输入质量的整体敏感度

如果三个难度填充率接近（如试卷分析：97.5%/100%/100%），说明该模板的字段提取鲁棒性强。
如果三个难度差异大（如教材建设申报：58.6%/100%/86.2%），说明简单版信息不足或中等版刚好对齐。

---

## 给Coze的总结

> 同一模板的知识文件，不管简单中等困难，里面的**事实数据是完全相同的**。区别只在于**表达形式**：
> - 简单 = 填表式，信息一目了然
> - 中等 = 叙述式，信息嵌入段落中
> - 困难 = 闲聊式，信息藏在口语转述里
> 
> 设计目的：测试Agent在不同输入质量下的信息提取能力，而不是测试数据是否齐全。
