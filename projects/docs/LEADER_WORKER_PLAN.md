## 迭代1：可切换、可验收的最小版本

- `AGENT_MODE=workflow`保留当前默认行为；`leader_worker`启用实验。
- Leader通过工具调用动态选择分析模板、提取材料、匹配、提交、校验、生成或追问；没有固定的阶段跳转。
- 材料提取按文件隔离上下文，最多3个并发调用；返回原文引用和来源，不直接修改表单。
- 匹配Worker返回字段ID、值、证据引用和置信度；代码检查未知ID、证据、低置信和同名来源冲突。
- 单一提交入口；生成前检查草稿是否全部提交，写入后检查值是否存在及OpenXML结构。
- 状态存入当前图会话，修改后使旧生成结果失效；保留同会话继续修改/重新生成。
- 每轮最多8次Leader决策、12次工具执行。失败、冲突、预算耗尽不得报告生成成功。
- 沿用现有模型、文档引擎、SSE接口和存储，不引入新框架或依赖。

## 验收与快速反馈

1. 离线用脚本模型驱动真实LangGraph、工具、文档引擎：正常链路、动态跳步、失败重试、冲突追问、修改后重验、跨会话隔离、SSE与取消。
2. 同一批合成资料/模板对比workflow和leader_worker：目标单元格正确数、虚填、调用次数、耗时、模型返回的Token用量。
3. 真实DeepSeek测试只使用示例资料；凭据仅从本地配置读取。没有有效本地密钥时报告“未执行”，不把离线结果冒称真实质量提升。
4. 运行现有测试、Lint、前端检查及四组CI；保留实验开关，不自动替换默认模式。

## 本轮边界

这是单进程内的受约束Supervisor，不是分布式Worker集群。未增加租户鉴权或执行破坏性数据库迁移。
首版限制单份材料正文12000字符、每批10份和200条事实，超过时明确返回限制，不静默截断。
原文引用校验只能验证引用及值的来源，不能证明模型完整理解语义；同义标签的复杂冲突仍需人工确认。
生成检查不等于逐页视觉保真。只有评测证据支持，才在后续迭代扩大自主性或切换默认。
